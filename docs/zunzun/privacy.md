# プライバシーポリシー

最終更新日: 2026年11月1日

iOSアプリ「ズンズン」（以下「本アプリ」といいます）における利用者の情報の取り扱いについて定めます。

## 1. 基本方針

**本アプリは、利用者の情報を開発者や第三者のサーバーに送信しません。** 本アプリにはサーバーがなく、アカウント登録もありません。記録・写真・設定は、すべて利用者の端末の中だけに保存されます。

## 2. 端末の中で扱う情報

| 情報 | 使う目的 | 保存場所 |
|---|---|---|
| 位置情報 | 歩いた道のり・距離・時間の記録、チェックポイントの判定 | 端末内（本アプリのデータ） |
| カメラで撮った写真、写真ライブラリから選んだ写真 | カードの作成 | 端末内（本アプリのデータ） |
| 作ったカード | 利用者が「写真に保存」を押したときに写真アプリへ保存 | 写真アプリ |
| 設定（チェックポイントの間隔、距離の単位など） | アプリの動作 | 端末内 |

- 位置情報は「歩く」を押してから「終わる」を押すまでの間だけ使います（画面を閉じている間も記録を続けます）。
- 地名の表示のため、位置（緯度・経度）を Apple の地図サービス（MapKit）に問い合わせることがあります。この通信は Apple のプライバシーポリシーに従います。地図の表示にも Apple の地図サービスを使います。
- 記録を削除すると、その道のりと本アプリ内の写真は端末から削除されます。写真アプリに保存したカードは削除されません。
- 本アプリを削除すると、本アプリ内の記録と写真はすべて削除されます。

## 3. 開発者が収集する情報

開発者は、利用者の情報を収集しません。広告・解析・トラッキングのためのツールも組み込んでいません。

## 4. 購入情報

アプリ内課金の購入・決済は Apple が行います。開発者は、利用者の氏名・支払い情報などを受け取りません。購入の状態は、Apple の StoreKit を通じて端末内で確認します。

## 5. 通知

チェックポイントの通知は、端末内で作るローカル通知です。外部のサーバーから送られるものではありません。

## 6. お問い合わせへの対応

メールでお問い合わせいただいた場合、いただいたメールアドレスと内容は、お問い合わせへの対応のためだけに使います。

## 7. 改定

本ポリシーを改定する場合は、本ページに掲載してお知らせします。
