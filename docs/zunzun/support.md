# ズンズン サポート

歩いた道のりを、一枚のカードに。ズンズンのサポートページです。

## 歩くときの注意（必ずお読みください）

1. **歩きながら画面を見ない** — 通知が来たら、立ち止まって安全な場所で撮ってください
2. **暑さ・寒さ・水分に気をつける** — 長く歩くときは、こまめに休んで水分をとってください
3. **入ってはいけない場所に入らない** — 私有地や立入禁止の場所、危険な場所には入らないでください
4. **電池の減りに注意** — 記録中は位置情報を使い続けるため、電池を多く使います。予備の電源があると安心です

## ご注意

- 距離や経路は位置情報から計算した目安で、実際と違うことがあります。
- このアプリの利用で生じた事故・けが・損害について、開発者は故意または重大な過失がある場合を除き、責任を負いません（[利用規約](terms.md) 第9条）。

## よくある質問

**Q: 画面を閉じても記録されますか？**
A: はい。「歩く」を押してから「終わる」を押すまで、画面を閉じても記録します。画面上部に位置情報を使っている印が出ます。

**Q: 電車や車に乗った分も距離に入りますか？**
A: 入りません。時速15kmを超える速さが続いた区間は乗り物とみなし、歩いた距離に数えず、線を点線で描きます。

**Q: 通知が来ません**
A: 設定アプリの「通知」でズンズンを許可してください。アプリを開いているときは、通知の代わりに画面でお知らせします。

**Q: 位置情報の許可は「常に」が必要ですか？**
A: いいえ。「アプリの使用中」で、画面を閉じている間も記録できます。

**Q: 電池の減りが気になります**
A: 記録中は位置情報を使い続けるため、電池を多く使います。長く歩く日は、予備の電源を持っていくと安心です。休憩中は一時停止もできます。

**Q: 記録や写真はどこに保存されますか？**
A: この iPhone の中だけです。外部に送ることはありません。カードは「写真に保存」を押したときだけ写真アプリに保存します。

**Q: 機種変更したら記録は引き継げますか？**
A: 本アプリの記録は端末の中だけに保存しているため、引き継げません。残したいカードは「写真に保存」しておいてください。

**Q: フルセットと1日パスの違いは？**
A: どちらも「測量帳」「余白」の柄、仕上げの選択、高画質の書き出し、全行程の地図が使えます。フルセットは買い切りでずっと、1日パスは購入から24時間だけ使えます。どちらも自動で更新・請求されることはありません。

**Q: 購入したのに使えません**
A: 設定の「購入を復元」をお試しください。購入時と同じ Apple アカウントでサインインしている必要があります。
