# プライバシーポリシー

最終更新日: 2026年10月30日

本プライバシーポリシーは、iOSアプリ「KoeMoji」（以下「本アプリ」といいます）における利用者情報の取り扱いについて定めるものです。

## 1. 基本方針

本アプリは、アカウント登録を必要としません。**録音した音声、読み込んだファイル、文字起こしの結果、要約、単語登録は、利用者の端末内でのみ処理・保存され、開発者のサーバーや第三者に送信されることはありません。** 開発者は利用者の音声や文字起こしを閲覧することができません。

本アプリには、利用者を追跡するトラッキングやアクセス解析の仕組みは含まれていません。

## 2. 本アプリが扱う情報

### 2.1 マイクの音声

- 利用者が録音を始めたときだけ、マイクの音声を取得します
- 音声は端末内で文字に起こされ、音声ファイルとして端末内に保存されます
- マイクの使用は iOS の「設定」アプリからいつでも許可を取り消せます

### 2.2 読み込んだ音声・動画ファイル

- 利用者が選んだファイルの音声だけを取り出し、端末内で文字に起こします
- 再生用に、音声を端末内に保存します（動画の映像は保存しません）

### 2.3 文字起こし・要約・単語登録

- 文字起こしの結果、要約、単語登録は端末内（SwiftData）にのみ保存されます。iCloud 同期や外部サーバーへのアップロードは行いません
- 要約は、端末上の言語モデル（Apple Intelligence）で作ります。本アプリは Apple のクラウド上で処理する仕組み（Private Cloud Compute）を使いません

### 2.4 書き出したファイル

- テキスト・字幕・Word ファイルは、利用者の操作によってのみ作成され、共有シートで利用者が選んだ宛先に渡されます。本アプリが自動で送信することはありません

## 3. 通信について

- **言語の音声データのダウンロード**: 文字起こしに使う言語の音声データは、初回の利用時に iOS の仕組みを通じて Apple のサーバーからダウンロードされます。このとき利用者の音声や文字起こしは送信されません
- **App内課金**: KoeMoji Pro の購入は Apple の StoreKit を通じて行われ、決済処理は Apple が行います。決済情報を開発者が取得・保存することはありません
- 上記のほか、本アプリが外部と通信することはありません

## 4. 第三者への情報提供

本アプリは利用者の情報を開発者のサーバーに送信しないため、開発者が第三者に提供することはありません。ただし、法令に基づき開示が求められた場合はこの限りではありません。

## 5. お子様のプライバシー

本アプリは、お子様の個人情報を意図的に収集することはありません。本アプリはそもそも個人情報を外部に送信しません。

## 6. データの削除

- 文字起こしは、アプリ内でいつでも削除できます（録音した音声もあわせて削除されます）
- 本アプリをデバイスから削除すると、アプリ内に保存されたデータはすべて削除されます。開発者がこれを復元することはできません

## 7. プライバシーポリシーの変更

開発者は、必要に応じて本プライバシーポリシーを変更することがあります。変更後の内容は、本ページに掲載した時点で効力を生じるものとします。取り扱う情報の範囲を広げる変更を行う場合は、アプリの更新内容等でお知らせします。

本アプリのご利用にあたっては、別途定める[利用規約](terms.md)もあわせてご確認ください。
