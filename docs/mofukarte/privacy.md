# プライバシーポリシー

最終更新日: 2026年9月22日

本プライバシーポリシーは、iOSアプリ「もふカルテ」（以下「本アプリ」といいます）における利用者情報の取り扱いについて定めるものです。

## 1. 基本方針

本アプリは、アカウント登録を必要としません。利用者が入力したペットのプロフィール、記録、予定、写真は、利用者のデバイス内にのみ保存され、開発者のサーバーや第三者に送信されることはありません。開発者は利用者の記録を閲覧することができません。

本アプリには、利用者を追跡するトラッキングやアクセス解析の仕組みは含まれていません。

## 2. 本アプリが扱う情報

### 2.1 利用者が入力する情報

- ペットの名前、種類、品種、性別、誕生日、お迎えした日、病院で伝えたいこと、メモ
- 体重、通院、投薬、予防・ワクチン、体調、メモなどの記録（日時、見出し、費用、本文を含みます）
- お世話の予定（名前、日時、くり返しの設定、メモ）

これらはデバイス内（SwiftData）にのみ保存されます。iCloud 同期や外部サーバーへのアップロードは行いません。

### 2.2 写真

- 利用者が写真ライブラリから選んだ写真を、プロフィールや記録に添えるために取り込みます
- 写真の選択にはシステムの写真ピッカーを使用します。本アプリが写真ライブラリ全体を読み取ることはありません
- 取り込んだ写真は縮小したうえでデバイス内にのみ保存されます

### 2.3 通知

- お世話の予定をお知らせするため、デバイス内でローカル通知を登録します
- 通知の登録はデバイス内で完結し、外部のサーバーを経由しません
- 通知の許可はいつでも iOS の「設定」アプリから変更できます

### 2.4 書き出したファイル

- 「病院で見せるレポート」（PDF）および「CSVで書き出し」は、利用者の操作によってのみ作成されます
- 作成したファイルは共有シートを通じて、利用者が選んだ宛先（ファイルアプリ、メール、印刷など）へ渡されます。どこへ渡すかは利用者が決め、本アプリが自動で送信することはありません

## 3. App内課金

- もふカルテ Pro の課金は Apple の StoreKit を通じて行われ、決済処理は Apple が行います
- クレジットカード情報等の決済情報は Apple によって管理され、開発者がこれらの情報を取得・保存することはありません
- 加入状態の確認のため、Apple から購入の記録（取引情報）を受け取りますが、利用者個人を特定する情報は含まれません

## 4. 第三者への情報提供

本アプリは利用者の情報を開発者のサーバーに送信しないため、開発者が第三者に提供することはありません。ただし、法令に基づき開示が求められた場合はこの限りではありません。

## 5. お子様のプライバシー

本アプリは、お子様の個人情報を意図的に収集することはありません。本アプリはそもそも個人情報を外部に送信しません。

## 6. データの削除

- 記録と予定は、アプリ内でいつでも個別に削除できます
- ペットのプロフィール画面から、その子の記録と予定をまとめて削除できます
- 本アプリをデバイスから削除すると、アプリ内に保存されたデータはすべて削除されます。開発者がこれを復元することはできません

## 7. プライバシーポリシーの変更

開発者は、必要に応じて本プライバシーポリシーを変更することがあります。変更後の内容は、本ページに掲載した時点で効力を生じるものとします。取り扱う情報の範囲を広げる変更を行う場合は、アプリの更新内容等でお知らせします。
